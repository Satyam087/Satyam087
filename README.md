## The "Predict → Decide → Act" Philosophy

I believe the next era of computing is **Agentic**, not merely conversational.

Every intelligent system I build follows one mental model:

| Phase | What It Means | How I Build It |
|-------|---------------|----------------|
| **Predict** | Understand data, context & possible outcomes | ML, retrieval, forecasting, probabilistic reasoning |
| **Decide** | Select the best path using structured reasoning | Agents, orchestration, business logic, state machines |
| **Act** | Execute actions in the real world | APIs, tools, databases, notifications & application workflows |

My goal is to build systems where LLMs are not isolated chat interfaces, but **reasoning and execution components inside reliable software architectures**.
